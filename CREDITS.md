# Image credits

All photography in these mockups is AI-generated iteration-placeholder
imagery — see below. No Wikimedia Commons photographs remain in use:
the eighteen downloaded for earlier design rounds were replaced by
generated images (batch 3 of `image-prompts.md`) or removed as unused;
their attributions remain in git history (v11.4 and earlier).

All schematic and diagram figures (SVG) are original works drawn for
these mockups and carry the project licence (CC BY-NC-SA 4.0).

## AI-generated iteration placeholders

Every `img/*.jpg` file was generated by the client with ChatGPT image
generation, from the prompts in `image-prompts.md` (which carries an
inventory of where each image appears). They are **placeholders for
design iteration and demonstration only** and must not appear on the
finally published site (HARD_RULES 12: no AI-generated imagery
presented as photography). The prompt file doubles as the shot list
for replacing them with real photographs. Any AI-provenance metadata
(C2PA) embedded in the files is deliberately retained — it truthfully
marks them as generated. Some images stand in for subjects they
resemble rather than depict exactly (the "TR-2" donor pedal is blue,
not tremolo green); alt text and captions describe what is actually
shown.
